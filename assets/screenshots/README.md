# Screenshots

Real renders of the susfile TUI, not mock-ups. Regenerate with
[`../screenshot.sh`](../screenshot.sh), which drives `assets/framegen` (a dev
tool that prints one `View()` frame with colour forced on) through
[`charmbracelet/freeze`](https://github.com/charmbracelet/freeze).

| File | View | Subject |
|---|---|---|
| `tui-map.svg` | the file map | `/bin/ls` |
| `tui-hex.svg` | the hex dump | `/bin/ls` |
| `tui-strings.svg` | the strings list | `/bin/tar` |
