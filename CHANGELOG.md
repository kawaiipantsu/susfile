## [0.1.1] - 2026-08-31

### Changed

- New logo. The TUI's top-left box now shows a magnifier over a fingerprint with
  the `s u s` / `f i l e` wordmark, a `forensic` tag and a `-=[ 53 . 55 . 53 ]=-`
  hex-for-SUS line, tinted to match the project mark. The logo box widened from
  14 to 24 columns. The README leads with the full `susfile_logo.png` banner.

  a release cut — so `v0.1.0`'s notes were published blank. It now extracts the

## [0.1.0] - 2026-08-30

First release. susfile reads one file and shows what it is — magic header,
MIME/type, hashes, ELF/PE/Mach-O structure, entropy and ent-style statistics —
with a defrag-screen **file map** of classified byte regions as the centrepiece
of an interactive TUI. It is a single static binary, makes no network
connections, and sends no telemetry.

### Added

- **Analysis engine** (`internal/analyze`): streaming MD5/SHA-1/SHA-256/CRC-32,
  whole-file Shannon entropy, a 256-bin histogram with byte-class fractions,
  ent-style statistics (arithmetic mean, chi-square, Monte-Carlo π, serial
  correlation), a curated magic-signature table plus pure-Go MIME detection,
  ELF/PE/Mach-O structure with per-section entropy (every parser wrapped so a
  crafted file yields warnings, not a panic), ASCII + UTF-16LE string
  extraction, and a windowed micro-block scan (`clamp(size/16, 1, 4096)` blocks,
  each measured over a ≥4 KiB window) with an 11-class content classifier and a
  kaomoji verdict. Nothing is written; no network call is made.
- **Reporters** (`internal/report`): `susfile --no-tui` renders a plain-text
  report with an ASCII class map, a legend and an entropy sparkline;
  `susfile --json` emits the stable `susfile.report/v1` schema (the full result,
  a rendered map, and the legend).
- **Interactive TUI** (`internal/tui`, Bubble Tea): a logo box and a label/value
  info box on top; the classified **file map** filling the lower half with a
  movable inspector cursor and an `Enter`-to-Hex jump; secondary Tab views
  (windowed entropy chart, byte histogram, scrollable hex dump, extracted-string
  list); and a footer with a live progress bar and the `⟦THUGS⟧ (c) 2026` stamp
  on every frame. Colour follows the terminal and `NO_COLOR` / `--no-color`;
  below 80×24 it shows a resize prompt. `susfile <file>` launches it by default
  when a terminal is attached.
- **CLI**: `susfile [flags] <file>` with `--no-tui`, `--json`, `--strings-min`,
  `--max-bytes`, `--map-size`, `--allow-special`, `--no-color`, `-` for stdin,
  and `susfile version`.
- **Build & packaging**: a `Makefile` with the development loop and a Linux-only
  cross-compile matrix — `linux/amd64`, `linux/386`, `linux/arm64`,
  `linux/arm` (v7) — all `CGO_ENABLED=0`, `-trimpath`, version-stamped.
  `make dist` builds a `.tar.gz` per arch plus `SHA256SUMS`; `make deb` builds
  four `.deb` packages (`amd64`, `i386`, `arm64`, `armhf`) via `dpkg-deb` with a
  man page, DEP-5 copyright and a Debian changelog, no `Depends`.
  `install.sh` is an arch-detecting, checksum-verifying installer that never
  calls `sudo`.
- **CI**: `Test` (fmt-check, vet, test, race), `Cross-build`, `Lint`
  (golangci-lint) and `Vulnerability scan` (govulncheck) on every push and PR,
  plus a **Branch flow** check that fails a PR opened against the wrong base.
  A `Release` workflow builds every artifact and publishes a GitHub release on a
  `v*` tag.
- **Docs**: `PROJECT.md` (the specification), `CLAUDE.md`, `docs/analysis.md`
  (the classifier spec), `docs/architecture.md`, `docs/tui.md`,
  `docs/packaging.md`, `docs/releases.md`, and a README with real SVG
  screenshots generated by `assets/screenshot.sh`.

### Known limitations

- **The classifier and verdict are heuristics**, not proofs. Thresholds are
  conservative and will be tuned (`type:idea` issues, the Ideas discussion).
- **`E` vs `Z`** (encrypted vs compressed) cannot be told apart by entropy below
  tens of kilobytes, so smaller high-entropy regions are shown as `Z` and the
  whole-file verdict carries the "packed / compressed / encrypted" nuance.
- **The magic table is curated, not libmagic** — it will miss and occasionally
  mislabel formats. `gabriel-vasile/mimetype` is used as a cross-check.
- **UTF-16 string extraction is little-endian only.**
- **The hex view buffers the first 4 MiB** of a large file; the rest is still
  scanned for the map, hashes and entropy (by sampling above `--max-bytes`).
- **`.deb` packages are unsigned**; verify downloads against `SHA256SUMS`.
- **Linux only.** macOS and Windows are not release targets.
